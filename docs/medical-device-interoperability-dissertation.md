# Dissertation: Advancing Medical Device Interoperability and Real-Time AI Monitoring

## Abstract
This dissertation explores the integration of heterogeneous medical IoT devices into a unified clinical ecosystem. By leveraging HL7/FHIR standards and unsupervised machine learning (Autoencoders/Isolation Forests), we propose a framework for real-time anomaly detection in clinical telemetry.

## Core Chapters
1. **Interoperability Challenges**: Addressing data silos in legacy hospital systems.
2. **Real-Time Ingestion**: Architectural patterns for high-frequency medical data.
3. **Unsupervised Learning**: Detecting sensor drift and device failure without labeled data.
4. **Clinical Impact**: Reducing alert fatigue and improving patient outcomes.
