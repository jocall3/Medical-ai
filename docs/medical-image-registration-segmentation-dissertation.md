# Dissertation: Advancing 3D Medical Image Analysis

## Abstract
This dissertation explores the integration of deep learning architectures for volumetric medical image registration and semantic segmentation. We propose a unified framework utilizing VoxelMorph for non-rigid alignment and 3D U-Net for organ delineation.

## Methodology
1. **Registration**: Unsupervised learning using spatial transformer networks.
2. **Segmentation**: Encoder-decoder architectures with skip connections.
3. **Clinical Impact**: Improving diagnostic accuracy through automated volumetric analysis.
