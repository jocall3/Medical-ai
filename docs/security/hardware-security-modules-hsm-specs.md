# FIPS 140-3 Level 4 HSM Specs

Global AI healthcare mesh master keys are protected by FIPS 140-3 Level 4 HSMs.

## Integration
- Active tamper-detection: The HSM erases all sensitive material upon physical or chemical intrusion.
- Multi-tenancy: Isolated containerized HSMs for different medical jurisdictions.
- Secure boot and attestation for all AI inference nodes.
