# Intrusion Detection System Architecture

This system provides a multi-layered defense for medical AI infrastructure. 

## Components
- **TrafficAnalyzer**: Real-time packet inspection.
- **SignatureMatcher**: Known threat database matching.
- **BehavioralAnomaly**: ML-based deviation detection.
- **ZeroDayDetector**: Deep learning model for novel threats.

## Compliance
Designed to meet HIPAA and NIST AI RMF requirements for data integrity and system availability.
