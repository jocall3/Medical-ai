# DNA Data Storage Cryptography

Synthetic DNA provides a stable, millennia-scale medium for storing EHR audit logs and master cryptographic keys. 

## Specifications
- Encoding: Binary-to-nucleotide mapping (A=00, C=01, G=10, T=11).
- Error Correction: Reed-Solomon codes integrated into the DNA strand to mitigate synthesis and sequencing errors.
- Security: Keys are derived from personalized genomic STRs (Short Tandem Repeats), ensuring that only the patient's own biological data can unlock their historical records.
