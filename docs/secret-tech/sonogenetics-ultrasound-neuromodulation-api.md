# Sonogenetics Ultrasound Neuromodulation API

## API Specification
This API provides the interface for focused ultrasound (FUS) neuromodulation. It allows for the non-invasive, precise targeting of neural circuits involved in addiction, such as the nucleus accumbens.

## Functionality
By modulating the firing rates of specific neural populations, the system disrupts the reward-seeking loops associated with substance abuse, effectively resetting the brain's addiction circuitry.
