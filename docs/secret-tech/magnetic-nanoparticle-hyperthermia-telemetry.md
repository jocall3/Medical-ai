# Magnetic Nanoparticle Hyperthermia Telemetry

## Telemetry Specs
This module tracks the thermal output of magnetic nanoparticles within tumor sites. It ensures that the alternating magnetic field (AMF) maintains a precise temperature range (42-50°C) to ablate cancer cells while sparing healthy tissue.

## Safety Logic
Integrated sensors provide real-time feedback to the AMF generator, adjusting field intensity to prevent thermal runaway and systemic toxicity.
