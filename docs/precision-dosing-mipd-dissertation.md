# Dissertation: Model-Informed Precision Dosing (MIPD)

## Abstract
This dissertation explores the integration of Bayesian inference and Reinforcement Learning to achieve closed-loop therapeutic control. We demonstrate that by combining population PK/PD models with real-time TDM data, we can significantly reduce toxicity and improve therapeutic efficacy.
