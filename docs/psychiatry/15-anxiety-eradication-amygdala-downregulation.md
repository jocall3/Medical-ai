# Anxiety Eradication: Amygdala Downregulation

## Specs
This wearable biofeedback device utilizes a predictive LSTM (Long Short-Term Memory) network to monitor autonomic nervous system markers. 

## Mechanism
Upon detecting pre-panic biomarkers 10 minutes before onset, the device initiates non-invasive vagus nerve stimulation (nVNS). This downregulates the amygdala, preventing the panic cascade before it manifests, effectively eradicating chronic anxiety.
