# Dissertation: AI-Driven Epidemic Forecasting

## Abstract
This dissertation explores the integration of mechanistic SEIR models with deep learning to revolutionize public health surveillance. By incorporating wastewater genomic data and mobility networks, we achieve unprecedented predictive accuracy.

## Methodology
We utilize Universal Differential Equations (UDEs) to allow neural networks to learn unknown transmission parameters, effectively bridging the gap between biological theory and data-driven forecasting.
